Anatomy of a link

Every SecretDrop link has three parts. The last one never leaves the browser.

  1. https://secretdrop.to/
    Address

    Loads this page. Browsers never send anything after the # to a server.

  2. #6c1e0f3a-8b2d-4f57-9a3e-1d4c7b9e2f60
    ID

    Your browser uses it to fetch one encrypted blob. Our server releases it once, then erases it.

  3. .q8Zr3VbN0xT5kLw7HcY2mPd9sJf4Ga6Ue1QoRiXnB-_
    Key

    Decrypts the secret on the recipient’s device. It never reaches our server.

With a password, the link carries no key at all. Your browser derives the key from the password with Argon2id.
