# Security policy

## Reporting a vulnerability

Please email **secretdropto@protonmail.com** and encrypt your message with our PGP key:

`8176 7114 C05B 3045 0071 2460 2630 DF27 86E3 39A6`

The key is on https://secretdrop.to/pgp and on keys.openpgp.org. Check the fingerprint before you use it.

You can also report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability".

Tell us what you found, how to reproduce it and what an attacker could do with it. If you write by email, attach your own public key so that we can answer encrypted. We read every report and reply as soon as we can. Please give us time to fix the issue before you publish it.

## Scope

In scope are the code in this repository and the live service at secretdrop.to and its onion address.

Please do not:

- test with secrets that are not your own
- run load tests or denial of service attacks against the live service
- send reports from automated scanners without a concrete finding

There is no bug bounty.
